# Change: add-auth-rbac-class-knowledge

## Why

CampusClaw 是面向中小学的教研智能体，覆盖学情分析、备课、命题、课堂与教研协同，教研材料与知识库是其能力底座。当前教研材料分散在群文件与网盘中，教师难以检索复用，班级之间也缺少数据边界。本变更先建立**身份、角色与班级隔离**：教师登录后上传并管理本班材料，学生仅可查看本班内容，材料解析后入库，为后续检索与智能问答打地基。

## What Changes

- **用户登录与会话**：教师、学生两类角色；账号密码登录；服务端会话表 + HttpOnly Cookie；登录限流；登出即失效；未登录访问受保护 API 返回 401 且不泄露任何业务数据。
- **角色权限（RBAC）**：教师可上传、查看、下载本班材料；学生只能查看、下载；学生调用上传接口 MUST 被拒绝（HTTP 403）且库与磁盘无变化。
- **班级隔离**：班级是数据边界（`class_id`）；所有业务查询在服务端按会话班级过滤；跨班按 ID 访问材料详情/文件 MUST 返回与"记录不存在"同形的 404。
- **材料上传与知识库入库**：教师上传 `.txt` / `.md`，解析正文后在**同一事务**写入 `materials` 与 `knowledge_entries`；校验失败或入库失败时数据库与磁盘均无残留；文件下载走鉴权 API，不静态暴露上传目录。
- **预置样本数据**：班级 A/B、教师 A、学生 A1/B1，两班可区分标题的种子材料；建立班级、用户、会话、材料、知识库条目、讲义、作业、助手、技能等核心数据结构；种子幂等。
- **Web 界面**：登录页 + 材料页；`/api/me` 驱动身份展示；401 回登录页；Markdown GFM 渲染且转义防脚本；本班范围内搜索。
- **安全与运行**：bcrypt 口令哈希；密钥与凭据仅来自环境变量，缺失即启动失败；唯一发布形态为 Docker Compose（web/api/db 三容器，仅 web 映射端口）；`GET /health` 仅做存活判定。
- **文档**：README 写明价值/场景/不做、Compose 启动步骤、单实例声明与跨班返回码约定；`.env.example` 入库，真实 `.env` 不入库。

## Capabilities

### New Capabilities

- `auth-upload`：登录与会话、按角色授权、按班级隔离、材料上传与知识库入库、材料详情与文件下载、预置数据、密码哈希与会话密钥、Docker Compose 部署与健康检查、最小 Web 界面等可验收行为。

### Modified Capabilities

（无——`openspec/specs/` 尚无主力规约。）

## Impact

- 新建前后端分离 Web 应用：React 18 + TypeScript + Vite 前端，Go（`net/http`）后端 API，Nginx 托管静态资源并同源反代 `/api`。
- 新建 MySQL 8.0 持久层：班级、用户、会话、材料、知识库条目及六类域表与幂等种子。
- 项目根新增 `docker-compose.yml`、`Dockerfile`（web/api）、`nginx.conf`、`.env.example`、`.dockerignore`。
- 本 change 以规约四件套为交付物；可运行实现按 `tasks.md` 在 Apply 阶段完成。

## Non-goals（非目标）

本 change **明确不做**以下内容（防止范围膨胀；数据表可预留字段，但不验收）：

- **检索与问答**：不做跨班检索、向量检索、全文检索、RAG、智能问答；本班列表内的前端筛选不算检索。
- **对话助手**：不做聊天界面、Agent 编排、技能包运行时。
- **作业流程**：不做作业提交、批改、成绩、审计与错题本。
- **平台超级管理员**：不设跨班管理员角色——它与"跨班返回 404"的隔离验收直接冲突，待隔离稳定后单独开变更设计其越权路径与操作审计。
- **身份与企业集成**：不做多校/多租户（租户即班级）、OAuth/OIDC、SSO、短信/邮箱验证码登录。
- **JWT / Bearer token**：登录态只走服务端会话 + Cookie，不签发 JWT，前端不使用 localStorage 存身份。
- **注册与改密**：账号由种子预置，不做注册、改密、找回口令流程；不做验证码、邮箱/短信登录。
- **富格式解析**：不做 PDF / Word / 图片解析，不做在线预览与编辑；仅支持 `.txt` / `.md`。
- **生产运维**：不做 K8s、多副本高可用、CI/CD、公网域名与 HTTPS 证书；登录限流状态存进程内存、会话存 MySQL，明确声明单实例部署，标准启动为 Docker Compose 本地/演示环境即可。
- **前端替代服务端安全**：不以隐藏按钮、禁用表单作为权限或班级隔离的唯一手段。
